# Samayamantri Technologies Website

Official website for Samayamantri Technologies.

## Website structure

- `index.html` - Main company website
- `ayurdrishti/` - AyurDrishti project website
- `careermap/` - CareerMap project website
- `indiaai/` - IndiaAI project website
- `sahaayamitra/` - SahaayaMitra project website
- `projects/` - Company projects overview
- `services/` - Company services
- `assets/css/` - Stylesheets
- `assets/js/` - JavaScript
- `assets/images/` - Website images
- `assets/data/` - Website data

## Deployment

The website is deployed from this GitHub repository to the Samayamantri Technologies domain through Hostinger.

Production domain:

https://samayamantritechnologies.com/

## Editing workflow

The local master copy is the primary working copy.

Recommended workflow:

1. Edit and test the website locally.
2. Commit and push changes to this repository.
3. Deploy the updated repository through Hostinger.
4. Test the live website.

Google Drive may be used as an additional backup/synchronization copy.

## Project websites

The major projects use directory-based URLs:

- `/ayurdrishti/`
- `/careermap/`
- `/indiaai/`
- `/sahaayamitra/`

Additional projects remain under `/projects/` until they are ready to become independent project sites.

## Important

Do not commit passwords, API keys, private credentials, database credentials, certificates containing private information, or other secrets to this repository.
